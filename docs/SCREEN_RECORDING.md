# Screen Recording Checklist (aim for 1:40–1:55)

## Before recording (not on camera)
- From repo root run `python3 -m http.server 8000`; open `http://localhost:8000/` in a desktop browser.
- Use a fresh/private window or clear localStorage so Rage Meter starts at 0. Keep browser zoom at 100% and window wide enough to show the full card.
- Record browser only; do not spend time showing code. Start with chaos ON (default).

## Shot list
1. **0:00–0:10 — Cohesion + premise:** show the polished sign-up card and Rage Meter. Briefly hover/focus the meter to reveal per-feature tally.
2. **0:10–0:25 — Username chaos:** type a username, click the reshuffling on-screen keyboard, then show the always-taken message. Use keyboard focus once to demonstrate accessibility.
3. **0:25–0:38 — Phone + password:** click a phone Jump button; enter `Rage!2026` and show all eight cumulative rules passing. Mention the witness is programmatically verified.
4. **0:38–0:55 — Submit chain:** move toward Submit to trigger a dodge or two; finish the form with a valid phone, accepted terms, then click through the three swapped-label confirmations. The misleading “No” is the continue action.
5. **0:55–1:15 — Profile chaos:** change display name and save; roll the visibility dice or choose π; scroll a little to reveal reverse-scroll behavior, then use the visible normalization toggle.
6. **1:15–1:35 — Stretch sampler:** show the 99% bar on sign-up if time, and on profile demonstrate the cookie reject dodge, bio character eater, and three-click toast. Do not attempt to show every stretch feature if the clock is tight.
7. **1:35–1:48 — Persistence + escape hatch:** show Rage Meter incremented, refresh or return to the header if useful, then open `?chaos=off` and show the calm-mode indicator. End on the polished UI.

## Recording guardrails
- Prioritize a complete sign-up-to-profile journey over showcasing every gimmick.
- If any interaction stalls, use a Jump button or the documented password witness; never spend more than 5 seconds stuck on one control.
- Keep the cursor visible and move deliberately. Do not expose personal browser tabs or notifications.
